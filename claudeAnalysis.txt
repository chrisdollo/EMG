  SECTION 1 — PIPELINE OVERVIEW (Current state)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Stage 1 — MATLAB  (data_processing_pipeline/)
  ───────────────────────────────────────────────
  Steps 1–4: CSV → sensor matrix → action blocks → gesture table → .mat
  Batch orchestration via prime_batch_process_raw_dir.m + put_emg_driver.m.
  Output: per-subject combinedCell .mat files, shape (N × 7), raw lengths.

  Stage 2 — Python  (2_data_preprocessing_pipeline.ipynb)
  ─────────────────────────────────────────────────────────
  For each gesture repetition:
    1. Bandpass filter 20–500 Hz (zero-phase Butterworth, order 4)
    2. Resample to 1500 samples (scipy.signal.resample, per channel)
    3. Per-channel z-score normalization
  Combine all subjects → model_ready_5_sub.mat  (1400 samples, 7 gestures)

  Stage 3 — Training & Evaluation  (3_model_evaluation.ipynb)
  ─────────────────────────────────────────────────────────────
  Trains 5 architectures on a single train/dev/test split.
  Training: Adam + ReduceLROnPlateau + early stopping + best-state restore.
  Shared modules: models.py (model classes), data_utils.py (loaders + functions)

  Stage 4 — Full-Dataset Retraining  (4_model_retrain_full.ipynb)
  ─────────────────────────────────────────────────────────────────
  Loads best checkpoint from weights/, retrains on all data, saves final .pt.

  SECTION 3 — REMAINING BUGS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [BUG 1] — Asymmetric padding adds an extra time sample in EEGNet
  ─────────────────────────────────────────────────────────────────
  Location: models.py — EEGNet.firstConv and EEGNet.separableConv

  Both convolutions use even kernels (64 and 16) with padding = kernel//2.
  PyTorch adds one extra time step:
    output_length = input_length + 2*(kernel//2) - kernel + 1
                  = input_length + 1

  This is harmless because the flattened size is computed dynamically via
  a dummy forward pass at init time. However, it deviates from the "same"
  padding intent of the original EEGNet paper.

  Fix (if strict compliance needed):
    Use padding=(0, kernel_length//2 - 1) in firstConv, or switch to
    F.pad() for explicit asymmetric padding.

  ──────────────────────────────────────────────────────────────────────────

  [BUG 2] — All models share the same dropout hyperparameter
  ──────────────────────────────────────────────────────────
  Location: 3_model_evaluation.ipynb — config cell (DROPOUT = 0.25)

  ShallowConvNet and DeepConvNet were designed with dropout=0.5 in the
  original paper. Forcing DROPOUT=0.25 on all five models may explain
  why DeepConvNet (59.64%) and CNN_LSTM (51.43%) underperform — they
  may be overfitting with insufficient regularization.

  Fix:
    Define per-model dropout defaults in the registry:
      model_registry = {
          'EEGNet':         lambda: models.EEGNet(dropout_rate=0.25),
          'ShallowConvNet': lambda: models.ShallowConvNet(dropout_rate=0.5),
          'DeepConvNet':    lambda: models.DeepConvNet(dropout_rate=0.5),
          'CNN_LSTM':       lambda: models.CNN_LSTM(dropout_rate=0.25),
          'EMG_TCN':        lambda: models.EMG_TCN(dropout_rate=0.25),
      }

  SECTION 4 — METHODOLOGICAL CONCERNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [CONCERN 1] — Subject-mixing in splits inflates reported accuracy  ⚠ HIGH
  ──────────────────────────────────────────────────────────────────────────
  The random 80/20 stratified split mixes repetitions from the same subject
  across train and test. This means the model sees signal characteristics
  from all 5 subjects during training, and tests on different repetitions
  of those same 5 subjects. This inflates accuracy because the model does
  not need to generalize to a new, unseen user.

  This likely explains why EMG_TCN hits 93.57% with only 1,400 samples —
  it has partially memorized subject-specific signal patterns rather than
  learning gesture-independent features.

  For rigorous evaluation (and publishable results), use Leave-One-Subject-
  Out (LOSO) cross-validation:
    - Train on 4 subjects, test on the held-out 5th
    - Rotate through all subjects and average results
    - This tests true generalization to new users

  ──────────────────────────────────────────────────────────────────────────

  [CONCERN 2] — Only 5 of 44 subjects used                          ⚠ HIGH
  ────────────────────────────────────────────────────────────────────────
  1,400 total samples is extremely small for deep learning. Adding subjects
  is the single most impactful thing you can do — the MATLAB and Python
  pipeline already supports it, just process more subject folders.

  Suggested target: 15–20 subjects (4,200–5,600 samples) minimum.
  Larger datasets will also make LOSO evaluation more meaningful.

  ──────────────────────────────────────────────────────────────────────────

  [CONCERN 3] — No data augmentation                                ⚠ MEDIUM
  ─────────────────────────────────────────────────────────────────────────
  With only 1,400 samples, the model is data-starved. EMG-specific
  augmentation during training can significantly improve generalization:
    - Gaussian noise injection (simulate electrode variability)
    - Random amplitude scaling (factor 0.8–1.2 per sample)
    - Time-shifting (random circular shift along time axis)
    - Channel dropout (randomly zero one channel per sample)

  Implementation: add an augment flag to BCIDataset in data_utils.py
  and enable it only for the training loader.

  ──────────────────────────────────────────────────────────────────────────

  [CONCERN 4] — No weight decay / L2 regularization                ⚠ MEDIUM
  ──────────────────────────────────────────────────────────────────────────
  Adam is called with default parameters (no weight_decay). On a small
  dataset like this, L2 regularization helps prevent overfitting, especially
  for the larger models (DeepConvNet, CNN_LSTM).

  Fix:
    optimizer = optim.Adam(model.parameters(), lr=LR, weight_decay=1e-4)

  ──────────────────────────────────────────────────────────────────────────

  [CONCERN 5] — Aggressive temporal downsampling (10,248 → 1500 samples)
  ────────────────────────────────────────────────────────────────────────
  Resampling from ~10,248 to 1500 samples is a ~6.8× reduction, giving an
  effective rate of ~750 Hz. While above Nyquist for EMG (~500 Hz), fast
  transients that distinguish similar gestures (e.g. G1 vs G2) may be
  distorted. Consider testing 2048 or 4096 as alternative target lengths.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 1 — Add more subjects (5 → 15+)          (High Impact)   │
  └───────────────────────────────────────────────────────────────────────┘
  Run the existing MATLAB + Python pipeline on more subject folders.
  No code changes needed — just process more data and re-run stage 2.
  Expected impact: +5–15% accuracy and much more reliable evaluation.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 2 — LOSO cross-validation                (Rigor)         │
  └───────────────────────────────────────────────────────────────────────┘
  Replace the random split with Leave-One-Subject-Out CV to get a
  meaningful, publishable accuracy number. The current 93.57% is likely
  optimistic due to subject-mixing. LOSO will give the true number.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 3 — Data augmentation                    (Medium Impact)  │
  └───────────────────────────────────────────────────────────────────────┘
  Add augmentation to BCIDataset (noise, amplitude scaling, time-shift).
  Enable only on the training loader. See Concern 3 for implementation.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 4 — Per-model dropout tuning             (Medium Impact)  │
  └───────────────────────────────────────────────────────────────────────┘
  Fix BUG 2 above. DeepConvNet and ShallowConvNet were designed for
  dropout=0.5. This alone may recover 5–10% for those two models.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 5 — Add weight decay to Adam             (Low-Med Impact) │
  └───────────────────────────────────────────────────────────────────────┘
  weight_decay=1e-4 in Adam helps prevent overfitting, especially useful
  given the small dataset size.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 6 — Sliding window data expansion        (Medium Impact)  │
  └───────────────────────────────────────────────────────────────────────┘
  Instead of one sample per gesture repetition, extract overlapping windows
  (e.g. 512 samples, 50% overlap) to multiply training data. This is
  especially valuable combined with more subjects.

  ┌───────────────────────────────────────────────────────────────────────┐
  │ IMPROVEMENT 7 — SVM + handcrafted features baseline  (Reference)      │
  └───────────────────────────────────────────────────────────────────────┘
  The putEMG paper reports ~90% with SVM + RMS features. Implementing
  this as a baseline gives a meaningful comparison point and validates
  that your preprocessing is correct. Features per channel per window:
    RMS, MAV, WL, ZC, SSC  (5 features × 24 channels = 120-dim vector)

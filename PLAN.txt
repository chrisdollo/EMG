putEMG Prime — Project Plan
============================
Last updated: 2026-04-22

Goal: Build a generalizable, channel-efficient sEMG gesture recognition system using
the putEMG dataset. The project progresses from within-subject baselines to full
cross-subject models, then narrows to a practical reduced-channel deployment suitable
for real BCI use.

--------------------------------------------------------------------------------
Phase 1 — Within-Subject Classification
Folder : within_subject/
Status : Deep learning DONE | Feature-based PENDING
--------------------------------------------------------------------------------

Reproduce and extend the original putEMG paper's within-subject classification
results using deep learning, establishing an internal benchmark before tackling
the harder cross-subject problem.

  a) Deep learning approach (raw signals, input shape 1×24×1500)
     Folder  : within_subject/deep_learning_approach/
     - 3-fold cross-validation, 38 subjects, seed 42
     - Models: EMG_TCN, EEGNet, ShallowConvNet
     - Results (grand mean ± std across subjects):
         EMG_TCN        97.47% ± 2.78%   ← best
         ShallowConvNet 93.50% ± 4.09%
         EEGNet         91.05% ± 5.56%
     - All three models exceed the published SVM+RMS baseline (~90%)
     - Status: DONE

  b) Feature-based approach (sliding-window hand-crafted features)
     Folder  : within_subject/feature_based_approach/  [to be created]
     - Use 50 libemg features per channel × 24 channels = 3192-dim per window
       Window size: 250 samples, stride: 50 samples → 26 windows per rep
       Feature vector per rep (sequence mode): (26, 3192)
     - Apply feature selection to identify the most discriminative features
     - Status: PENDING

Phase 2 — Cross-Subject Generalization  (LOSO Baseline)
Folder : generalizable/baseline_models/
Status : Deep learning DONE | Feature-based PENDING
--------------------------------------------------------------------------------

Train models that generalize to completely unseen subjects using Leave-One-Subject-Out
(LOSO) evaluation — the gold standard for cross-subject generalization.

  Deep learning approach:
     Folder  : generalizable/baseline_models/deep_learning_approach/
     Status  : COMPLETE — all 44 folds run for all 3 models
     Models  : EMG_TCN, EEGNet, ShallowConvNet

     Results (LOSO, 44/44 folds, all subjects):
       EMG_TCN        80.76% ± 12.38%   ← best
       EEGNet         77.23% ± 12.05%
       ShallowConvNet 73.38% ± 11.94%

     Infrastructure:
       - Checkpointing: per-subject .pt files; completed folds skipped on resume
       - MODEL_TYPE variable in model.ipynb to switch between models
       - Per-model weight subfolders: weights/EMG_TCN/, weights/EEGNet/, weights/ShallowConvNet/
       - Per-model result logs: results_log_EMG_TCN.txt, etc.

  Feature-based approach:
     Folder  : generalizable/baseline_models/feature_based_approach/
     Input   : (26, 3192) sequence per rep — 50 libemg feature groups × 24 channels
     Extractor: public/feature_extraction.py (batch_extract with skip logic)
     Models  : LSTM, GRU, Transformer
     Status  : Feature extraction added; training not yet run

Phase 3 — Channel Clustering
Folder : generalizable/clustering/
Status : PENDING
--------------------------------------------------------------------------------

24 channels is too many for a practical, wearable BCI. The goal is to reduce the
electrode count to 8 representative channels without a significant loss of accuracy.

  - Use agglomerative clustering to group the 24 channels into 8 clusters,
    selecting one representative channel per cluster.
  - Clustering performed independently for deep learning and feature-based approaches.

Phase 5 — Reduced-Channel Model
Folder : generalizable/efficient_model/
Status : PENDING
--------------------------------------------------------------------------------

Retrain the cross-subject baseline models using only the 8 channels identified in
Phase 3, and measure accuracy loss vs the 24-channel baseline.

  a) Deep learning version
     Folder  : generalizable/efficient_model/deep_learning_approach/
     - Same EMG_TCN / EEGNet / ShallowConvNet on (1, 8, 1500) input

  b) Feature-based version
     Folder  : generalizable/efficient_model/feature_based_approach/  [to be created]
     - Same pipeline on 8 channels; feature-based input shrinks to (26, ~530) per rep

  Target: match or closely approach the 24-channel cross-subject baseline
          accuracy with one-third the electrode count.

--------------------------------------------------------------------------------
1. DATASET
--------------------------------------------------------------------------------

Source      : putEMG (Poznan University of Technology, Kaczmarek et al. 2019)
Subjects    : 44 able-bodied subjects processed (03–07, 08–20, 22–27, 29–31,
              33–36, 38–39, 42–43, 45–51, 53–54)
              IDs 21, 28, 32, 37, 40, 41, 44, 52 not present in dataset
Channels    : 24 sEMG electrodes (ring around the forearm)
Sampling    : 5120 Hz
Gestures    : 7 classes — G1, G2, G3, G6, G7, G8, G9
Protocol    : ~40 reps/gesture/subject  (2 sessions × 5 series × ~4 reps)
              Each rep: ~280 samples per subject after preprocessing

Raw data    : one CSV per session per subject
              24 EMG channels + 1 trajectory label (0=rest, 1–9=gesture, -1=ignore)

--------------------------------------------------------------------------------
2. PIPELINE
--------------------------------------------------------------------------------

STAGE 1 — Signal Preprocessing
  Code : data_preprocessing/preprocessing.py
         data_preprocessing/driver.ipynb
  Steps: bandpass 20–500 Hz (zero-phase Butterworth, order 4, before resampling)
         → resample to 1500 samples
         → per-channel z-score normalization
  Output: /Volumes/KRIS/data/UG_per_subject/emg_gestures_SS_U.mat  (44 files)
  Shape: combinedCell (N_reps, 7), each cell (1500, 24) float64

STAGE 2A — Feature Extraction (for feature-based models)
  Code : data_preprocessing/feature_extraction.py
         data_preprocessing/driver.ipynb
  Window: size=250 samples (~49 ms), shift=50 samples (~10 ms) → 26 windows/rep
  Features: 8 per channel × 24 channels = 192-dim vector per window
    MAV, RMS, WL, ZC, SSC, VAR, MNF, MDF

STAGE 2B — Deep Learning Data Loading (for CNN/TCN models)
  Code : formats/deep_learning_approach/model/emg_datahandler.py
  Loads preprocessed .mat files at runtime; reshapes to (N, 1, 24, 1500)
  LOSO splits via make_loso_loaders() / loso_folds() / generate_loso_configs()

3. APPROACHES & FORMAT OVERVIEW
--------------------------------------------------------------------------------

  Format 1 — flat_rep     : (4992,) per rep   [26 windows × 192, concatenated]
    Models     : SVM, XGBoost, MLP
    Use case   : offline; simplest baseline
    Status     : extraction implemented; training pending

  Format 2 — flat_window  : (192,) per window
    Models     : SVM, XGBoost, MLP, 2D CNN
    Use case   : offline + real-time; largest dataset; majority vote for offline
    Status     : extraction implemented; training pending

  Format 3 — sequence     : (26, 192) per rep
    Models     : LSTM, GRU, BiLSTM, Transformer
    Use case   : offline; captures temporal dynamics
    Status     : extraction done for 26 subjects; 18 remaining; training pending

  Format 4 — raw signal   : (1, 24, 1500) per rep   [end-to-end deep learning]
    Models     : EEGNet, ShallowConvNet, EMG_TCN  (best: 93.57%)
    Use case   : offline; model learns its own representations
    Status     : COMPLETE — see results below

  NOTE: splits must be at the rep level (not window level) to avoid data leakage.

--------------------------------------------------------------------------------
4. MODEL ARCHITECTURES  (Format 4 — deep learning)
--------------------------------------------------------------------------------

  All models: NUM_CLASSES=7, NUM_CHANNELS=24, INPUT_SAMPLES=1500
  Code: formats/deep_learning_approach/model/deep_learning_models.py

  EEGNet         — depthwise + separable convolutions; standard BCI architecture
  ShallowConvNet — temporal conv → band-power pooling (x² → avgpool → log)
  DeepConvNet    — deeper block-based CNN                [currently disabled]
  CNN_LSTM       — spatial CNN + temporal LSTM           [currently disabled]
  EMG_TCN        — dilated temporal convolutions + residual connections  [BEST]

  Training config (model.ipynb):
    Optimizer    : Adam
    LR scheduler : ReduceLROnPlateau (factor=0.5, patience=5, min_lr=1e-6)
    Early stop   : patience=5, min_delta=0.002
    Max epochs   : 20
    Dropout      : 0.1 (EEGNet, ShallowConvNet), 0.25 (EMG_TCN)
    Best-state   : checkpoint restored from best val epoch before test eval

6. BUGS FOUND AND FIXED
--------------------------------------------------------------------------------

  [FIXED — 2026-04-09]  dtype bug in evaluateFinal()
    actual = torch.tensor([]) and predicted = torch.tensor([]) created float32
    empty tensors. torch.cat with int64 label tensors silently promoted to
    float32, corrupting confusion matrix class labels (showed 0., 1., ... as
    floats). Did not affect accuracy calculation. Fixed: dtype=torch.int64.

  [FIXED — 2026-04-09]  dead loop in loso_folds()
    A partially-converted generator had for fold in range(n_folds): wrapping
    a return — the loop was dead code with no subject rotation. Fixed: removed
    the loop; loso_folds() is now a clean single-fold function. Multi-fold
    iteration is handled externally via generate_loso_configs().

8. WEAKNESSES & GAPS
--------------------------------------------------------------------------------

  1. EMG_TCN LOSO RESULT UNKNOWN [highest priority gap]
     The 93.57% figure is from a pooled 5-subject split. EMG_TCN has not been
     run under LOSO. The gap between EMG_TCN (93.57%) and EEGNet (86.07% LOSO)
     may disappear or reverse once EMG_TCN is evaluated cross-subject.

  2. ONLY 1 LOSO FOLD COMPLETED
     One fold (subject 12 as test) is not enough to characterize generalization.
     Need at minimum 5–10 folds with different test subjects for a stable mean ± std.

  3. NO FEATURE FORMAT BASELINES
     Formats 1, 2, 3 have no accuracy numbers. Cannot compare against 93.57% or
     answer whether hand-crafted features compete with learned representations.

  4. G9 HARD TO CLASSIFY CROSS-SUBJECT
     EEGNet predicted G9 45 times (roughly correct) but temporal models
     historically fail on G9. After per-rep z-score removes amplitude, G9
     (little finger pinch) becomes nearly indistinguishable from G6–G8 for
     waveform-pattern models. ShallowConvNet's band-power features handle this
     better. No architectural fix applied yet.

  5. FORMAT 3 FEATURE EXTRACTION INCOMPLETE
     26 of 44 subjects have sequence features extracted. Remaining 18 need
     processing before full-dataset Format 3 training.

  6. CHANNEL CLUSTERING NOT FINALIZED
     The 24→8 channel reduction experiment has code but no results yet. The
     192-dim vs 64-dim accuracy comparison is still unmeasured.

  7. DeepConvNet AND CNN_LSTM NOT RETESTED AT SCALE
     Both disabled after poor 5-subject performance. With 44 subjects and
     LOSO they may be viable — more data benefits deeper architectures.

Recording Protocol
  • ~40 repetitions per gesture per subject across 2 sessions (5 series each)
  • Gestures: G1, G2, G3, G6, G7, G8, G9 — hand and finger flexions
  • Electrodes arranged as a sparse matrix around the forearm
  • ~280 gesture repetitions per subject after preprocessing
  • Raw format: one CSV per recording session (24 channels + trajectory label)
Why This Dataset
  • Public benchmark with a published SVM baseline of ~90% (within-subject)
  • 44 subjects — sufficient scale for LOSO cross-subject evaluation
  • Known electrode layout → enables anatomical validation in Phase 4
Preprocessing Steps
  • MATLAB pipeline — CSV → detect gesture boundaries → combinedCell (N_reps × 7) · data_preprocessing/gesture_splitting_pipeline/
  • Bandpass filter — 20–500 Hz, zero-phase Butterworth order 4, applied before resampling to prevent aliasing · preprocessing.py
  • Resampling — downsampled to 1500 samples per repetition
  • Normalization — per-channel z-score per repetition
  • Output: (1500, 24) float64 per rep, 44 .mat files · /Volumes/KRIS/data/UG_per_subject/

Sliding window → 8 features × 24 ch → (26, 192) sequence · data_preprocessing/feature_extraction.py
Feature Extraction Detail
  • Window size: 250 samples (~49 ms at 5120 Hz)
  • Window stride: 50 samples (~10 ms)
  • 26 windows per 1500-sample repetition
  • Initial: 8 features per channel — MAV, RMS, WL, ZC, SSC, VAR, MNF, MDF
  • Later: expand to 50 features per channel then select best 8–12
  • Current shape per rep: (26, 192) = 26 windows × 8 × 24
Data leakage prevention: splits are at the repetition level, never the window level. Windows from the same rep must not appear in both train and test sets.

Shared Training Configuration
  • Optimizer: Adam
  • LR scheduler: ReduceLROnPlateau — factor 0.5, patience 5, min LR 1×10⁻⁶
  • Early stopping: patience 5, min delta 0.001–0.002
  • Dropout: 0.1 · Best-epoch checkpoint restored before test evaluation
  • Within-subject: max 30 epochs, 3-fold CV per subject
  • Cross-subject (LOSO): max 20 epochs, 1 subject held out per fold
  • Shared code: public/emg_loader.py  ·  public/deep_learning_models.py
LOSO: train on 43 subjects, test on 1 completely unseen subject. Repeated for all 44 subjects. Mean ± std over all folds is the reported metric.
Additional architectures may be explored in later phases. Current three models (EMG_TCN, EEGNet, ShallowConvNet) form the established baseline.

Phase 3 — Channel Clustering

To Be Implemented · generalizable/clustering/
⬜ Not yet started
Reduce 24 electrodes to 8 representative channels using agglomerative clustering
24 sEMG channels is too many for a practical wearable BCI. This phase uses unsupervised clustering to identify groups of highly correlated channels and selects one representative from each group — reducing the electrode count by two-thirds while preserving the key signal variation.
  • Deep learning clustering — cluster channels based on learned feature representations from the trained LOSO model
  • Feature-based clustering — cluster channels based on their hand-crafted feature vectors (MAV, RMS, etc.)
  • Compare both sets — do DL and feature-based approaches select the same 8 channels?
  • Validate on LOSO — retrain models on the 8 selected channels and compare accuracy to the 24-channel baseline
Depends on: Phase 2 (LOSO baseline complete)  ·  Phase 1b (feature extraction for all 44 subjects)

Phase 4 — Anatomical Validation of Clusters

To Be Implemented · generalizable/clustering/
⬜ Not yet started
Cross-reference selected channels with the putEMG electrode-to-muscle-group map
The putEMG paper provides the anatomical positions of all 24 electrodes relative to forearm muscle groups. This phase validates whether the channels selected in Phase 3 correspond to the same anatomical muscle group — as would be expected from physiology — or reveal unexpected cross-muscle correlations.
  • Map clusters to anatomy — use the putEMG electrode layout to label each cluster with its corresponding muscle group
  • Produce electrode diagram — annotated forearm illustration showing selected channels and their muscle groups
  • DL vs feature-based comparison — do both approaches converge on the same anatomical groups?
  • Interpret discrepancies — if a selected channel belongs to a different muscle group than expected, understand why
Depends on: Phase 3 (channel clusters identified)

Phase 5 — Reduced-Channel Model

To Be Implemented · generalizable/efficient_model/
⬜ Not yet started
Retrain all models on the 8 channels from Phase 3 and measure the accuracy trade-off
Using the 8 representative channels identified in Phase 3, this phase produces the final reduced-channel models and benchmarks them against the 24-channel LOSO baseline. The goal is to demonstrate that practical deployment (fewer electrodes, simpler hardware) is achievable with minimal accuracy loss.
  • Deep learning (8-channel) — same EMG_TCN / EEGNet / ShallowConvNet on input shape (1, 8, 1500)  ·  generalizable/efficient_model/deep_learning_approach/
  • Feature-based (8-channel) — same pipeline; if using best 8–12 features: 64–96-dim per window vs 192-dim baseline  ·  generalizable/efficient_model/feature_based_approach/
  • LOSO evaluation — same 44-fold protocol as Phase 2 for a direct comparison
  • Report accuracy gap — quantify how much accuracy is lost by using 8 instead of 24 channels
Depends on: Phase 3 (8 channels selected)  ·  Phase 2 (24-channel LOSO baseline as reference)

Phase 6 — Real-Time Data Collection

Future Work
⬜ Not yet started · details TBD
Evaluate the system in an online, streaming setting with new participants
All previous phases operate offline on pre-recorded data. This final phase validates the system in a realistic real-time scenario, streaming live sEMG signals and classifying gestures with low latency. Details will be defined once Phases 1–5 are complete and the reduced-channel model is finalized.
  • Hardware setup — configure streaming sEMG acquisition with the 8-channel reduced electrode set
  • Online preprocessing — replicate the offline bandpass → resample → z-score pipeline in real time
  • Subject-adaptive calibration — brief calibration session (a few reps per gesture) to fine-tune the model for the new participant
  • Latency and accuracy evaluation — measure both classification accuracy and end-to-end latency
Depends on: All Phases 1–5 complete  ·  Reduced-channel model finalized

  • Full LOSO infrastructure — single notebook, MODEL_TYPE variable, per-model weight subfolders, per-model result logs, skip/resume logic

  • EEGNet LOSO complete — 77.23% ± 12.05% · all 44/44 folds

  • libemg feature extraction — public/feature_extraction.py · 50 feature groups × 24 ch = 3192-dim/window · skip logic included
The Core Challenge
  • 17-point accuracy gap: within-subject 97.47% → LOSO 80.76% (best model)
  • ±12 pp std shared by all models — subject-specific signal variation is the bottleneck, not architecture
  • High validation (~91–94%) but variable test accuracy — model sees consistent training populations but cannot predict unseen subjects

Highest-Leverage Experiment

  • Expected to close most of the 97.47% → 80.76% gap

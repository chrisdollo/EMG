putEMG Prime — Project Plan
============================
Last updated: 2026-06-13

Goal: Build a generalizable, channel-efficient sEMG gesture recognition system using
the putEMG dataset. The project progresses from within-subject baselines to full
cross-subject models, then narrows to a practical reduced-channel deployment suitable
for real BCI use.

--------------------------------------------------------------------------------
Phase 1 — Within-Subject Classification
Entry  : runners.run_within(...) — invoked from baseline.ipynb / scripts/run_baseline.py
Status : COMPLETE (2026-06-13)
--------------------------------------------------------------------------------

Reproduce and extend the original putEMG paper's within-subject classification
results, establishing internal benchmarks before tackling the harder cross-subject
problem.

  a) Deep learning approach (raw signals, input shape 1×24×1500)
     Entry   : runners.run_within(type='deep_learning', ...)
     Weights : weights/baseline/within_dl/
     Results : results/baseline/results_baseline_within_DL_{model}.txt
     - 3-fold cross-validation, 44 subjects, seed 42
     - Models: EMG_TCN, EEGNet, ShallowConvNet
     - Status: COMPLETE

  b) Feature-based approach (41 single-scalar libemg features)
     Entry   : runners.run_within(type='feature_based', ...)
     Weights : weights/baseline/within_feat/
     Results : results/baseline/results_baseline_within_feature_{model}.txt
     - 3-fold cross-validation, 44 subjects, seed 42
     - Input: 41 features × 24 channels = 984-dim per window, channel-major.
       26 windows/rep → (N_reps, 26, 984). Folds are rep-level (no leakage).
     - Models (WITHIN_FEATURE_MODELS):
         SVM        — RBF kernel, C=50, window-level training, majority vote
         FeatureMLP — 3-layer MLP on per-window features, majority vote
     - Status: COMPLETE

Phase 3 — Channel Clustering
Folder : clustering & analysis/
Status : NOT YET RUN
--------------------------------------------------------------------------------

24 channels is too many for a practical, wearable BCI. The goal is to reduce the
electrode count to 8 representative channels without a significant loss of accuracy.
Only feature-space clustering is used — raw-signal clustering was found to be less
informative and has been archived.

  clustering.ipynb — feature-space correlation clustering
    - Loads all subjects' pre-extracted feature data (N_reps × 26 × 984)
    - Separates per-channel feature vectors: shape (N_total_windows, 24, 41)
      (channel-major layout → channel c is columns [c*41 : (c+1)*41], a clean slice)
    - Computes per-channel mean signature: (24, 41) matrix
    - Computes 24×24 Pearson correlation matrix between channel signatures
    - Applies agglomerative hierarchical clustering (Ward linkage) → k=8 clusters
    - Silhouette sweep over k=4–12 to validate k=8 is reasonable
    - Selects medoid per cluster (most central channel in feature space)
    - Visualizations: dendrogram, 24×24 heatmap, forearm ring layout
    - Saves: feat_representative_channels.npy  (8,) 0-indexed
             feat_cluster_labels.npy           (24,) cluster assignments

Phase 5 — Reduced-Channel Model
Notebook : efficient.ipynb
Status : NOT YET RUN (depends on Phase 3)
--------------------------------------------------------------------------------

Retrain the cross-subject baseline models using only the 8 channels identified in
Phase 3, and measure accuracy loss vs the 24-channel baseline.

  a) Deep learning version
     Notebook: efficient.ipynb
     - Loads feat_representative_channels.npy from clustering & analysis/
     - Slices X[:, :, channels, :] → input shape (N, 1, 8, 1500)
     - Same LOSO loop, checkpointing, and logging as the 24-channel DL baseline
     - Final cell compares 8-channel vs 24-channel accuracy side-by-side
     - Models: EMG_TCN, EEGNet, ShallowConvNet

  b) Feature-based version
     Notebook: efficient.ipynb
     - Same pipeline on 8 channels; SVM (C=50) + FeatureMLP
     - Channel-major layout makes this a column slice of the 24-channel features:
       41 features × 8 channels = 328-dim per window (no re-extraction needed)

  Target: match or closely approach the 24-channel cross-subject baseline
          accuracy with one-third the electrode count.
